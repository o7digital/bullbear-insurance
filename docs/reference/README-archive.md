# Bull & Bear — Atelier (Astro 5)

Segunda propuesta visual, con estética editorial premium, imagen arquitectónica original, composición cinematográfica y diseño responsive. Mockup en español para presentar al cliente.

## Cómo abrir

```bash
npm install
npm run dev
```

Abrir la URL que aparezca en Terminal. Para versión producción: `npm run build`.

## Vista sin instalar Astro

Abrir el archivo `Bull-Bear-Preview-Autonoma.html` en el navegador. Este archivo incluye CSS, JavaScript y la imagen dentro del mismo HTML.

## Páginas y funcionalidades

- Home Astro / `src/pages/index.astro`
- Estilos / `public/styles.css`
- JavaScript / `public/site.js`
- Imagen original generada para esta demostración / `public/assets/architecture-hero.webp`
- Menú adaptable, enlaces ancla, FAQ desplegables y formulario simulado

## Atención

**Es un prototipo, no un sitio web oficial.** No reemplaza los servicios ni contenidos legalmente aprobados por el cliente. El formulario no recopila ni envía información, se requieren API/backend, consentimiento de privacidad y pruebas de producción antes del lanzamiento.

El branding B&B es una interpretación conceptual. Revisar nombres de servicios, condiciones de productos, avisos regulatorios, teléfonos y dirección con el cliente.

Para publicar de verdad, completar páginas de servicio, CMS, revisión de texto legal, accesibilidad, redirecciones desde WordPress, SEO y analítica.
